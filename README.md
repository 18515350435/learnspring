# learnspring

纯静态 HTML 项目。

## 目录结构

```
├── index.html      页面入口
├── css/
│   └── style.css   样式
└── js/
    └── main.js     脚本
```

## 本地预览

无需构建工具，直接打开 `index.html` 即可；或起一个本地服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
