# 星光小马妆造馆

一个纯静态（无构建、无后端）的小马收集 + 装扮小游戏：做任务 → 家长审核通过 → 解锁饰品和小马 → 自由打扮。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000       玩家端
# 浏览器访问 http://localhost:8000/admin.html   家长管理端（初始密码 1234）
```

直接用浏览器双击打开 `index.html` 也能跑，但 Safari 在 `file://` 协议下会禁用本地存储，
页面顶部会给出提示；想让两端数据互通，请用上面的方式起一个本地服务。

## 目录结构

```
├── index.html      玩家端（妆造台 / 任务中心 / 收集图鉴）
├── admin.html      家长管理端（审核任务 / 解锁管理 / 自定义任务 / 数据维护）
├── css/
│   └── style.css   全部样式
└── js/
    ├── data.js     静态数据：小马、饰品、任务与奖励映射
    ├── pony.js     SVG 小马渲染引擎（含全部饰品的矢量绘制）
    ├── store.js    共享存储层 + 任务状态机
    ├── app.js      玩家端交互
    └── admin.js    家长端交互
```

## 玩法与逻辑

- **收集**：初始拥有紫悦 + 3 件基础饰品；其余 5 只小马、26 件饰品都要靠任务解锁。
- **任务**：共 24 个预设任务，覆盖阅读、才艺、运动、劳动、作息等，每个任务产出 1～2 件奖励。
- **审核**：孩子点「我完成啦」并留言 → 任务进入待审核 → 家长在管理端通过或驳回（可写理由，孩子能看到）→ 通过后奖励立刻进入衣柜。
- **手动干预**：管理端可以随时解锁或收回任意饰品/小马，也能新建自定义任务并指定发放哪些奖励。
- **数据**：存档写在浏览器 localStorage（key `pony_studio_v1`），两个页面实时互通，支持导出/导入 JSON。

## 技术说明

- 所有形象均由 SVG 图形拼装，`js/pony.js` 里按层顺序叠加：翅膀 → 后鬃毛 → 身体 → 头 → 角/耳 → 刘海 → 眼睛 → 口鼻 → 腮红 → 眼妆 → 发饰 → 额饰 → 头饰 → 眼镜 → 颈饰。新增饰品只需在对应 slot 下增加一个返回 SVG 片段的函数。
- 无第三方依赖，无网络请求。
