# 星光小马妆造馆 · 云上城堡

一个纯静态（无构建、无后端）的小马收集 + 装扮 + 养成小游戏：做任务 → 家长审核通过 → 解锁饰品和小马 → 自由打扮 → 回云上城堡照顾它们、布置房间、赚星星币买东西。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000              玩家端
# 浏览器访问 http://localhost:8000/admin.html    家长管理端（首次进入时自行设置密码）
```

直接用浏览器双击打开 `index.html` 也能跑，但 Safari 在 `file://` 协议下会禁用本地存储，
页面顶部会给出提示；想让两端数据互通，请用上面的方式起一个本地服务。

## 手机版单文件

想发到手机上玩，先打包：

```bash
node build-single.js
```

会生成 **`星光小马-手机版.html`**（约 220 KB：样式与全部脚本内联，零外部依赖，零网络请求）。
把它发到手机（微信 / QQ / 邮件都行），用浏览器打开就能玩，**家长端也在同一个文件里**，导航里一键切换。

手机版做的适配：8 个页签改成横向滑动、按钮触摸区放大到 44px、家园房间与小马放大、
拖家具和抓星星时不会带动页面滚动、适配 iPhone 刘海与底部安全区、禁止双击缩放。

> **关于存档**：浏览器不给 `file://` 页面写 localStorage，所以**直接打开本地文件能玩，但关掉后进度不保留**
> （页面顶部会有黄条提示）。想让进度保存下来，把该文件放到任意网页空间里访问即可。

## 🔐 家长端怎么进（两道关）

管理端**没有内置默认密码**，前端也不再写死任何密码，流程分两种：

- **第一次打开**：先答对一道乘除口算题 → 设置 4～8 位数字密码 → 顺便选孩子年级 → 进入。
  （先答题是为了防止孩子自己打开页面就把密码设了）
- **之后每次打开**：输入密码 → 再答对一道乘除口算题 → 才进得去。

口算题难度跟着「数据与设置」里的**孩子年级**走，除法保证整除：

| 年级 | 题型 | 例子 |
| --- | --- | --- |
| 1-2 年级 | 表内乘除 | `7 × 8 = ?`、`56 ÷ 7 = ?` |
| 3-4 年级 | 两位数 × 一位数 | `23 × 7 = ?`、`161 ÷ 7 = ?` |
| 5-6 年级 | 两位数 × 两位数 | `23 × 14 = ?`、`322 ÷ 14 = ?` |

答错会自动换一道新题（不给重答同一题的机会）。

> ⚠️ **忘记密码没有找回入口**：只能清除浏览器本站点数据后重新设置，但那样存档也会一起没。
> 所以养成习惯——在「数据与设置」里偶尔**导出一次 JSON 存档**存好。

## 玩法总览

一条完整的循环：**做任务 → 家长通过 → 拿星星币 + 经验** → **去商店买吃的/玩具/家具** →
**回云上城堡照顾小马（喂、洗、哄睡、摸摸）** → **爱心、等级、成就一起涨** → 解锁更高级的商品。

- **收集**：初始拥有紫悦 + 3 件基础饰品；其余 5 只小马、26 件饰品都要靠任务解锁。
- **任务**：共 24 个预设任务，覆盖阅读、才艺、运动、劳动、作息等，每个任务产出 1～2 件奖励。
- **审核**：孩子点「我完成啦」并留言 → 任务进入待审核 → 家长在管理端通过或驳回（可写理由，孩子能看到）→ 通过后奖励立刻进入衣柜，同时发放 `星级 × 10` 星星币和 15 点经验。
- **手动干预**：管理端可以随时解锁或收回任意饰品/小马。
- **👨‍👩‍👧 自定义任务（家长可增 / 可改 / 可删）**：

  | 操作 | 入口 | 说明 |
  | --- | --- | --- |
  | 新增 | 家长端「数据与设置」→ **新增自定义任务** | 填任务名称、要求说明，勾选完成后要发的奖励（饰品 / 小马都可以，可多选），再设 **1～10 星**（通过后发 `星级 × 10` 星星币） |
  | 修改 | 自定义任务列表每行 **编辑** 按钮；或「任务总览」里自定义任务的 **编辑** | 弹窗里**预填原来的名称、说明、奖励和星级**，改完点「保存修改」。**任务 id 不变**，所以孩子已提交/已审核的记录不会断链 |
  | 复制 | 「任务总览」里预设任务的 **改成我的** 按钮 | 把预设任务复制成一条自定义任务并立刻打开编辑弹层，适合"奖励我想换一下"的场景 |
  | 删除 | 每行 **删除** 按钮 | 会二次确认 |

  弹窗里还有「已选 N 项」实时计数和「清空」按钮；玩家端任务卡上会显示这条任务能拿多少 ⭐。
- **破解开关**：两个页面顶部导航都有一个「🔒 破解开关」按钮，点一下解锁全部小马和饰品（调试用），再点一下会**精确还原到开启前的解锁状态**，不会误删孩子自己挣来的奖励；状态写在存档里，两端同步。

## 🏠 家园 · 云上城堡

- **美术**：房间整体重画为云上城堡风格 —— 拱形落地窗、窗外云海、窗帘、地板光斑、云朵踢脚线、前景飘云；夜晚会变暗、窗外换成月亮与星星、亮起夜灯。
- **自由活动**：每匹小马自己随机挑地方走，走到就歇一会儿、聊两句，越靠前越大（近大远小）；饿了会跑向零食，困了会自己趴下睡。
- **需求系统**：每匹小马有 🍎 吃饱 / 🛁 干净 / 💖 心情 / 💤 精力 四项需求，会随时间缓慢下降（离线也按时间衰减，最多累计 8 小时）。数值低了头顶会冒告急图标，走得也会变慢。
- **🚽 上厕所**：小马还有一项隐藏的「便意」，会慢慢上涨，**吃完东西涨得更快**。憋不住时头顶冒 🚽、自己跑去**云朵马桶**蹲下解决；上完会**自动走到星星洗手台洗手**（房间里有洗手台的话）。没有马桶时它会小声抱怨「想上厕所…可是没有马桶…」，提示你去商店买一个。每次如厕 +2⭐ +1♥，洗手 +1⭐，都能解锁对应成就。
- **互动**：点小马弹出菜单 —— 🫶 摸摸（冒爱心、说话）、🛁 洗澡、💤 哄睡、🚽 上厕所（憋不住时按钮会变琥珀色跳动）、📋 档案（四项需求条 + 便意条 + 爱心 + 性格），还能直接喂背包里的食物和玩具。
- **性格**：每匹小马有隐藏性格（小吃货 / 开心果 / 爱干净 / 瞌睡虫 / 黏人精），在档案里查看。
- **工具条**：🍎 撒零食、🚽 去上厕所（带憋着的小马集体去）、🔔 集合啦、🎲 换装扮、🌙 昼夜切换、📷 拍张照、🎨 换墙纸地板、🔊 音效开关、🎁 今日打卡。
- **随机惊喜**：房间里会不定期飘过 ⭐ 和 🎁，点一下能白捡 5～10 星星币。
- **布置**：买到的家具会出现在房间里，**按住就能拖到喜欢的位置**，位置会存进存档。
- **天气**：每天随机一种天气（晴天 / 多云 / 下雨 / 下雪），显示在顶部状态条。
- **音效**：摸摸、吃东西、打卡、金币都是 Web Audio 现场合成（不需要任何音频文件），可一键静音。

首次进入会弹打卡窗，连续打卡越久每天领得越多（`10 + min(连续天数-1, 10) × 5`，最多 60 ⭐），断签会重新计算。

## ☁️ 云同步（Supabase，可选）

本地存档默认存在浏览器 localStorage 里，**换设备 / 清缓存会丢**。配置 Supabase 云同步后，存档会自动备份到云端，换手机也能一键恢复。

### 一次性准备（约 5 分钟）

1. 到 [supabase.com](https://supabase.com) 注册（免费档即可），新建一个项目（区域选新加坡/东京，国内访问更稳）
2. 项目里打开 **SQL Editor**，粘贴执行：

   ```sql
   create table saves (
     code text primary key,
     data jsonb not null,
     updated_at timestamptz not null default now()
   );
   alter table saves enable row level security;
   create policy "saves_all" on saves for all to anon using (true) with check (true);
   ```

3. 到 **Settings → API** 复制两样东西：**Project URL**（形如 `https://xxxxx.supabase.co`）和 **anon key**（`anon` / `public` 那个）

### 游戏里配置

家长端 → 「数据与设置」→ **云同步（Supabase）**：

- 粘贴 URL 和 anon key，点「帮我生成」得到一个**同步码**（记到备忘录！），保存即开启
- 之后每次游戏内存档变化会自动防抖上传（2.5 秒合并一次）；打开游戏时云端有更新的存档会自动恢复
- **换新设备**：在新设备上输入**同一个同步码**（URL/key 也要填），打开游戏自动恢复存档
- 「立即上传 / 从云端恢复」可手动操作，冲突时按「最后写入者优先」

### 安全说明

- anon key 本来就是设计为可以出现在前端代码里的（保护靠数据库规则），加上同步码是随机 10 位（32 种字符，不可枚举），别人既猜不到码也改不了你家数据
- 配置只存在**你自己浏览器的 localStorage**，不会写进这个公开仓库
- ⚠️ 免费层有流量配额（约 500MB / 5 万月活），自家玩绰绰有余；存档单份约 2KB

## 🚀 后端部署（Spring Boot on Render，可选）

`server/` 下是一个最小的 Spring Boot 3（Java 17）存档服务，直连 Supabase Postgres，可部署到 Render 免费档，替代前端直连 Supabase REST 的方式（适合以后加复杂业务逻辑时扩展）。

### 本地运行

```bash
cd server
mvn spring-boot:run        # 需要本机 JDK 17 + Maven
# 指定 Supabase 连接串：
DATABASE_URL='jdbc:postgresql://aws-0-xxx.pooler.supabase.com:6543/postgres?user=postgres.xxx&password=xxx' mvn spring-boot:run
```

接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/saves/{code}` | 读存档（与前端 saves 表结构一致） |
| PUT | `/api/saves/{code}` | 写存档，body 即 data（jsonb） |

### 部署到 Render 免费档（约 10 分钟）

1. 仓库根目录已有 `render.yaml`（Blueprint 清单）
2. 到 [render.com](https://render.com) 用 GitHub 账号登录 → New → **Blueprint** → 选本仓库
3. 创建时它会要求填 `DATABASE_URL`：去 Supabase → Project Settings → **Database → Connection pooling**（端口 **6543**），拼成 JDBC 串：
   `jdbc:postgresql://aws-0-xxx.pooler.supabase.com:6543/postgres?user=postgres.xxx&password=你的密码`
4. 首次构建约 5 分钟，之后每次 push 到 master 自动重新部署
5. 免费档 15 分钟无流量会休眠，首次访问冷启动约 30-60 秒，`/api/health` 可用于唤醒

注意：必须用 **Connection pooling（6543）** 连接串，不要用直连（5432），否则实例休眠恢复后会占满 Supabase 连接数。数据库密码在 Supabase → Settings → Database 里可以重置。

## 技术说明

- 所有形象均由 SVG 图形拼装，`js/pony.js` 里按层顺序叠加：翅膀 → 后鬃毛 → 身体 → 头 → 角/耳 → 刘海 → 眼睛 → 口鼻 → 腮红 → 眼妆 → 发饰 → 额饰 → 头饰 → 眼镜 → 颈饰。新增饰品只需在对应 slot 下增加一个返回 SVG 片段的函数。
- 房间、家具、窗户全部是手绘 SVG 字符串，无图片资源；小马与家具用 DOM + CSS 动画 + 单条 `requestAnimationFrame` 循环驱动。
- 无第三方依赖，无构建步骤；存档写在浏览器 localStorage（key `pony_studio_v1`），两个页面实时互通（`storage` 事件），支持导出/导入 JSON。
- 云同步（`js/cloud.js`）直接 fetch 调 Supabase REST API（无 SDK），配置存 localStorage（key `pony_cloud_v2`），不进仓库；上传防抖 2.5s 合并，启动时比对 `savedAt` 决定是否用云端覆盖本地（最后写入者优先）。
